One-line office joke for the make.fun bounty "Make the AI Judge Laugh".
Prize: 2 USDC. The entry is a single line about office life, judged
head-to-head by an AI judge on how true, surprising, tight and original
it is.

## Run

Set MAKEFUN_OUTPUT_DIR to the output directory and run:

    python3 main.py

This writes entry.txt (UTF-8, no trailing newline) into that directory.
Standard library only, no network.
